## 1. Manual configuration of the HPE Slingshot Fabric Manager

Instructions to configure the HPE Slingshot Fabric Manager are provided in the _HPE Slingshot Installation Guide for CSM (S-9004)_.

For systems with HPE Slingshot NICs, also follow the instructions in
the "Install SHS for CSM" section of the _HPE Slingshot Host Software Installation and Configuration Guide (S-9009)_.

Once this step has completed:

- The HPE Slingshot Fabric Manager is configured
