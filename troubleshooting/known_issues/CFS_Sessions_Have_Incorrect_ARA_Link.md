# CFS Sessions Have Incorrect ARA Link

In CSM 1.5.0, the [CFS](../../glossary.md#configuration-framework-service-cfs) API gives incorrect
[ARA](../../glossary.md#ara-records-ansible-ara) links for
[CFS sessions](../../operations/configuration_management/CFS_Sessions.md).
This issue is fixed in CSM 1.5.1 and later.

For more information on ARA, see [Ansible Log Collection](../../operations/configuration_management/Ansible_Log_Collection.md).
